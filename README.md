# Exercício 02

Página pessoal sobre a autoria do aluno, com apresentação, competências e formação.

## Conteúdo
- Foto de apresentação
- Descrição pessoal
- Lista de objetivos e competências
- Secções de formação e idiomas
- Rodapé com autoria

## Como visualizar
1. Abrir `index.html` num navegador.
2. Verificar que a imagem local `CTE-digital-768x512.jpg` está disponivel no mesmo diretório.

## Objetivo
Aplicar estrutura de texto, listas e organização de conteúdos em uma página de apresentação pessoal.
